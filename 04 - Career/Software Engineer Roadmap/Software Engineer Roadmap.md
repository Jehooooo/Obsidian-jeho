## 🏗️ Phase 1: Foundations

These are the core skills every software engineer needs.

### Programming Fundamentals
- [x] Python basics — variables, loops, functions, data types
- [x] Python OOP — classes, inheritance, encapsulation
- [x] Python advanced — decorators, generators, error handling
- [x] Programming logic — conditionals, loops, problem-solving patterns

### Version Control
- [x] Git basics — init, add, commit, push, pull
- [x] Branching and merging
- [x] Git workflow — feature branches, pull requests
- [x] GitHub — repositories, issues, README

### Databases
- [x] SQL basics — SELECT, INSERT, UPDATE, DELETE
- [x] JOINs and relationships
- [x] Database design and normalization (1NF, 2NF, 3NF)
- [x] Indexes and optimization

### Data Structures & Algorithms
- [x] Arrays, lists, dictionaries
- [x] Stacks and queues
- [x] Sorting algorithms (bubble, merge, quick sort)
- [x] Searching algorithms (linear, binary search)
- [x] Big O notation
