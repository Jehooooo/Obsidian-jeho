## Common Questions

### Technical
1. What is the difference between SQL and NoSQL?
2. Explain how REST APIs work
3. What is the Virtual DOM in React?
4. How do you handle authentication in a web app?
5. What is database normalization?

### Behavioral
1. Tell me about a challenging project you worked on
2. How do you handle tight deadlines?
3. Describe a time you had to learn something quickly
4. How do you approach debugging?
5. Why do you want to be a software engineer?
