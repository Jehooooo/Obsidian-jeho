# Project Templates

> Use these templates when starting a new project.

## Available Templates

- [[Project Template]] — Full project documentation template
- [[Bug Report Template]] — Bug tracking template
- [[Meeting Notes Template]] — Meeting documentation

## How to Start a New Project

1. Create a new folder in `03 - Projects/`
2. Copy the [[Project Template]] into your new folder
3. Rename it to your project name
4. Fill in the Project Overview section
5. Start adding tasks and features

## Project Workflow

```
Idea → Planning → Development → Testing → Deployment → Completed
```

1. **Idea** — Document the concept and goals
2. **Planning** — Design database, UI, and architecture
3. **Development** — Build features, track tasks
4. **Testing** — Test features, document bugs
5. **Deployment** — Deploy and document
6. **Completed** — Write lessons learned
