# 📝 Personal Notes & Daily Habits

> General personal notes, productivity guidelines, and engineering mindset reminders.

---

## ⏰ Daily Engineering Routine

1. **Morning Focus (First 2 Hours):** Tackle the highest leverage task (core feature code or complex debugging) before checking messages or notifications.
2. **Deep Work Sessions:** 45-minute focused sprints with 10-minute breaks.
3. **Daily Note Capture:** Log problems, solutions, and key commits in [[Daily Notes]] before closing the IDE.
4. **Physical & Mental Health:** Regular breaks, hydration, and exercise to prevent mental fatigue during long coding stretches.

---

## 💡 Mindset & Principles

- **Make it Work, Make it Right, Make it Fast:** Don't prematurely optimize. Get a working prototype first, refactor for clarity and maintainability, then optimize performance if needed.
- **Fail Fast & Log Well:** Good error logs and clear debug assertions save hours of guesswork.
- **Learn in Public:** Write clean READMEs, maintain GitHub activity, and document projects so others can learn from your work.
